# DailyFlow UI 设计

## 1. 设计目标

DailyFlow 是长期使用的个人工作工具，界面需要支持高频记录、快速扫描和长时间阅读。视觉方向应安静、清晰、信息密度适中，不采用营销页式大标题或装饰性卡片堆叠。

设计关键词：

- 工作台，而不是展示页。
- 记录优先，导航稳定。
- 密集但可扫描。
- 本地优先状态可见。
- 桌面操作高效，Web 窗口宽度自适应。
- 颜色用于区分状态，不作为唯一信号。

## 2. 信息架构

主导航：

1. Dashboard
2. Daily Journal
3. Timeline
4. Knowledge Base

8. Data Management

底部辅助区：

- Settings
- 存储/保存状态
- 可选 AI 状态
- 应用版本


### 3.1 桌面布局

```text
┌──────────────────────────────────────────────────────────────┐
│ Top Context Bar: breadcrumb / search / save / actions        │
├──────────────┬──────────────────────────────┬────────────────┤
│ Left Nav     │ Main Workspace               │ Context Panel  │
│ 232px        │ fluid                        │ 280-360px opt. │
│              │                              │                │
│ Dashboard    │                              │ Backlinks      │
│ Journal      │                              │ Metadata       │
│ Timeline     │                              │ Tasks / Tags   │
│ Knowledge    │                              │ History        │
│ Tasks        │                              │                │
│ Search       │                              │                │
│ Analytics    │                              │                │
│ Data         │                              │                │
├──────────────┴──────────────────────────────┴────────────────┤
│ Status Bar: 已保存 14:32 / 本地 SQLite / 当前日期             │
└──────────────────────────────────────────────────────────────┘
```

尺寸建议：

- 左导航 224 至 248 px。
- 上下文面板 280 至 360 px。
- 桌面最小窗口 1024 x 700 px。
- 主工作区最大内容宽度由内容类型决定，编辑器正文约 760 至 880 px，不强行居中到超窄阅读列。

### 3.2 Web 布局

- 宽屏与桌面类似，但无原生窗口边框和关闭拦截。
- 小于 1180 px 时上下文面板改为右侧抽屉。
- 小于 900 px 时左导航收为图标栏或顶部导航。
- 小于 720 px 时为单列，编辑器工具栏横向滚动，关键操作保留。
- V1 不把手机原生体验作为验收目标，但页面不能横向溢出。

### 3.3 导航行为

- 当前模块高亮，不使用装饰性大色块。
- 导航项使用 Lucide 图标 + 文字；折叠时保留 tooltip 和可访问名称。
- 浏览器前进/后退与内部导航一致。
- 离开未保存编辑器前触发保存协调器。

## 4. 视觉语言

### 4.1 布局

- 页面不是由浮动卡片拼接而成。
- 区域使用背景层次、分隔线和对齐建立层级。
- 卡片只用于重复条目、弹窗或独立工具，圆角不超过 8 px。
- 不把卡片放在卡片内。
- 页面主体占满可用宽度，使用内边距和最大内容宽度约束。

### 4.2 颜色

使用 CSS 变量和 Tailwind 语义 token：

```css
:root {
  --background: 42 33% 98%;
  --foreground: 220 16% 14%;
  --surface: 0 0% 100%;
  --surface-muted: 45 20% 95%;
  --border: 220 12% 86%;
  --primary: 172 44% 30%;
  --primary-foreground: 0 0% 100%;
  --accent: 26 58% 48%;
  --success: 150 46% 34%;
  --warning: 35 78% 40%;
  --danger: 2 64% 48%;
  --info: 210 62% 44%;
}
```

方向：

- 暖白背景、深灰正文、青绿色主色、琥珀色点缀。
- 避免全屏深蓝、紫蓝渐变、米色单色系和所有内容使用同一色相。
- 状态色保持稳定：成功绿色、警告琥珀、危险红色、信息蓝色。
- 热力图使用主色的 5 个离散色阶，并同时提供日期和数值文本。

### 4.3 字体与排版

- UI 字体使用系统中文字体栈，正文优先可读性。
- 编辑器正文 16 至 17 px，行高 1.7。
- UI 正文 14 px，辅助信息 12 至 13 px。
- 标题层级不超过 4 个视觉级别。
- 字距保持 0，不使用负字距。
- 等宽字体只用于代码、ID、快捷键和统计数字。
- 不使用随视口宽度缩放字号。

### 4.4 间距与圆角

- 基础间距单位 4 px，常用 8、12、16、24、32。
- 控件高度 32 或 36 px，主要按钮可 40 px。
- 输入框、按钮和菜单圆角 6 px。
- 卡片和对话框圆角 8 px。
- 不使用胶囊形状承载普通命令。

## 5. 组件策略

- 基础组件来自 shadcn/ui，样式通过语义变量定制。
- 图标统一使用 Lucide。
- 工具按钮优先图标 + tooltip，明确的命令使用图标 + 文字。
- Toggle 用于二元设置，Checkbox 用于多选，Segmented Control 用于模式切换，Select/CommandMenu 用于选项集合。
- 数值参数使用 slider/stepper/input，不用文字按钮堆积。
- Tooltip 不仅重复可见文字，还说明不熟悉图标的行为。

## 6. Dashboard

### 6.1 布局

```text
Good afternoon / 2026-10-30
[继续记录今天] [新建待办]                  保存状态

Today Journal                         Tasks
今日标题、摘要、继续写作              今天 / 逾期

Recent Journals        Recent Knowledge  Activity
最近编辑列表           最近知识条目      12 周热力图

Storage / Backup reminder
```

设计原则：

- 不使用营销 Hero。
- 日期和今天日志是首屏第一视觉信号。
- 操作按钮靠近相关工作区。
- 热力图是 Dashboard 的低优先级信息，不占满首屏。
- 空状态提供真实可执行入口。

### 6.2 组件尺寸

- 顶部欢迎区高度随内容，不设置固定巨大高度。
- 日志摘要和任务列表使用密集行布局。
- 卡片高度由内容决定，使用 CSS grid 对齐，不因 hover 或标签变化抖动。

## 7. Daily Journal

### 7.1 页面结构

```text
┌ Breadcrumb: Journals / 2026-10-30   Save status / actions ┐
├──────────────── Main editor ───────────────┬ Context ┐
│ Date, title, tags                           │ Date   │
│ Formatting toolbar                          │ Tags   │
│ Tiptap body                                 │ Tasks  │
│                                             │ History│
│                                             │ Attach.│
└─────────────────────────────────────────────┴────────┘
```

### 7.2 顶部操作

- 前一天/后一天，使用图标按钮和 tooltip。
- 日期选择器。
- 手动保存（图标）。
- 更多菜单：导出 Markdown、历史版本、删除。

### 7.3 编辑器工具栏

至少包含：

- 撤销/重做图标。
- 段落/标题选择。
- 加粗、斜体、删除线、行内代码。
- 列表、引用、代码块、链接。
- 图片/附件。
- 结构化块插入。

使用固定高度工具栏，按钮固定尺寸，避免激活态改变布局。窄屏工具栏横向滚动，不换行挤压正文。

### 7.4 保存状态

状态文案：

- `未保存`
- `保存中...`
- `已保存 HH:mm`
- `保存失败，点击重试`
- `存在版本冲突`

状态在状态栏和编辑器顶部各出现一次即可，不重复堆叠。

### 7.5 上下文面板

可折叠区块：

- 日期与时区。
- 标签。
- 关联任务。
- 来源导入文件。
- 历史版本。
- 附件。

V1 不放入大量低频设置，避免破坏写作专注。

## 8. Timeline

### 8.1 视图

Segmented Control：

- 月历
- 时间线
- 热力图

### 8.2 月历

- 每个日期格显示日期、日志标题摘要点、任务截止点。
- 今天和选中日期有明显但克制的边框。
- 非当前月日期降低对比度，但保持可读。
- 点击日期进入 Journal。
- 右侧或下方显示选中日期详情摘要。

### 8.3 时间线

- 按日期倒序分组。
- 每条显示日期、标题、摘要、标签、任务状态。
- 同一日期多个结构化问题可展示计数，但不展开全文。
- 使用 cursor 分页，滚动加载时保持位置稳定。

### 8.4 热力图

- 12 周网格。
- 色阶基于正文字符数或记录数，必须在图例中说明口径。
- Hover/focus 显示日期、日志摘要、字符数。
- 颜色之外同时显示 tooltip/可访问文本。

## 9. Knowledge Base

### 9.1 列表

```text
Knowledge                        [新建]
Filters: 类型 | 标签 | 最近更新

Issue        WebView2 启动崩溃         10-29
Solution     清理缓存并升级 Runtime     10-29
Decision     本地存储采用 Repository 分离 10-26
```

交互：

- 类型用菜单或分段筛选。
- 标签可多选。
- 关键词筛选调用本地搜索或标题过滤，不伪造全文范围。
- 列表行显示类型、标题、摘要、更新时间、来源标记。

### 9.2 详情

- 标题、类型、状态。
- 编辑器正文。
- 可选结构化字段区。
- 来源日志、关联条目、标签、附件。
- 保存状态与历史版本。

### 9.3 问题与解决方案

问题详情优先显示：

- 现象。
- 影响范围。
- 排查过程。
- 根因。
- 最终方案。
- 预防措施。

这些字段可选，不强制填写；未知字段折叠而不是塞满页面。

## 10. Tasks

- 顶部 Segmented Control：今天、即将到期、全部、已完成。
- 列表行包含 checkbox、标题、截止日期、优先级、关联图标。
- 行内编辑标题，Enter 保存，Escape 取消。
- 右侧详情抽屉编辑备注、关联实体、优先级和日期。
- 完成使用 checkbox，行为必须可撤销或有明确反馈。
- 不使用 Kanban 作为 V1 默认视图。

## 11. Search

### 11.1 入口

- 顶部搜索按钮。
- `Ctrl/Cmd+K` 打开命令式搜索浮层。
- `/search` 提供完整搜索页。

### 11.2 交互

- 输入后 200 ms 防抖。
- 上下键选择，Enter 打开，Escape 关闭。
- 结果按类型分组或显示类型标记。
- 过滤器：实体类型、日期、标签。
- 显示命中片段，高亮不能依赖纯颜色。
- 索引 stale 时在结果上方显示“索引待重建”及操作。

### 11.3 空状态

- 无输入：展示最近搜索和可用过滤入口。
- 无结果：展示已应用过滤器，提供清除过滤器。
- 索引失败：显示重建索引，不清空用户查询。

## 12. Analytics

### 12.1 结构

- 周期切换：周、月、年。
- 上一周期/下一周期。
- 统计卡片行，不使用大块营销卡片。
- 趋势图、标签分布、任务完成摘要。
- 报告编辑区。

### 12.2 图表

- 使用可访问的本地图表库。
- 每个图表有标题、口径和文本摘要。
- 颜色不是唯一区分。
- 小屏不压缩标签到不可读，改为表格或滚动。
- 数字使用 tabular numerals。

### 12.3 Report 编辑

- 默认生成结构化草稿。
- 用户编辑后进入统一 Tiptap 保存管线。
- AI 辅助按钮明确标注可选项和数据范围。

## 13. Data Management

### 13.1 区块

1. 存储概览。
2. TXT 历史导入。
3. 数据导出。
4. 备份与恢复。
5. 索引和健康检查。
6. 危险操作。

### 13.2 导入向导

步骤：

1. 选择目录。
2. 扫描进度。
3. 预览与问题处理。
4. 确认策略。
5. 提交进度。
6. 结果统计。

每个步骤保持同一页面，避免多层弹窗。异常行可直接展开查看原因。

### 13.3 状态

- 显示存储类型：SQLite 或 IndexedDB。
- 显示数据库 schema 版本。
- Web 显示浏览器持久化状态和估算配额。
- 显示最后备份时间。
- 备份过期只做温和提醒，不制造阻塞。

## 14. 设置

- 外观：主题、密度。
- 编辑：自动保存间隔、历史版本保留。
- 日期与区域：周起始日、时区显示。
- 快捷键查看和冲突提示。
- AI Provider：默认关闭，显示数据发送策略。
- 隐私与诊断：本地日志、诊断包导出。

V1 不加入插件、主题市场或复杂账户设置。

## 15. 交互状态

每个异步页面至少设计：

- 初次加载骨架。
- 空状态。
- 成功状态。
- 局部错误。
- 可重试失败。
- 离线/本地存储不可用。
- 权限或配额不足。
- 冲突状态。

禁止：

- 加载失败显示空白页。
- 用 Toast 承载必须被处理的冲突。
- 保存失败后仍显示“已保存”。
- 删除按钮无确认。
- 只靠颜色表达问题。

## 16. 响应式与布局稳定性

- 定义固定尺寸的工具栏、图标按钮、保存状态、数据行和编辑器工具栏。
- 动态内容使用 min-width、min-height、wrap 和 overflow 规则，不改变邻近控件位置。
- 最长单词、日期、中文标题和附件名必须能换行或截断并有 tooltip。
- 表格列使用合理最小宽度，横向滚动在容器内而不是整页。
- 弹窗宽度使用 min/max/clamp，不用纯视口字体缩放。

## 17. 可访问性

- 所有交互可由键盘完成。
- 焦点环明显且不被 `outline: none` 移除。
- 语义化标题、导航、main、dialog、toolbar。
- Icon button 必须有 `aria-label`。
- 菜单支持方向和 Escape。
- 快捷键提供可发现的帮助面板。
- 编辑器工具栏状态使用 `aria-pressed` 等语义。
- 错误消息用 `aria-live` 或焦点移动到错误摘要。
- 对比度达到 WCAG 2.1 AA。

## 18. 平台差异

| 交互 | Windows | macOS | Web |
| --- | --- | --- | --- |
| 修饰键 | Ctrl | Cmd | 根据平台显示 Ctrl/Cmd |
| 关闭保护 | Tauri close request | Tauri close request | beforeunload 可提示，保存尽力完成 |
| 文件选择 | 原生对话框 | 原生对话框 | File System Access 或 input |
| 右键菜单 | 原生/自定义一致 | 原生/自定义一致 | 浏览器菜单优先，除非明确需要 |
| 外部链接 | 系统浏览器 | 系统浏览器 | 新标签页 |

不在 UI 文案中写死 `Ctrl` 或 Windows 路径。快捷键和路径显示由平台适配层生成。

## 19. 可用性验收

- 1024 x 700、1440 x 900、1280 x 800 下核心布局无重叠。
- Windows 125%/150% 缩放可用。
- macOS Retina 文字和分隔线不模糊。
- 浏览器 375 px 宽度下主要内容不横向溢出。
- 中文长标题、英文长单词、长路径和错误码均不破坏布局。
- 键盘可完成新建日志、编辑、保存、搜索、创建任务和打开数据管理。
- 主要页面在加载中、空、错误和正常状态下都可理解。

## 20. UI 待确认决策

1. **默认主题**：建议浅色为默认，提供深色；若用户主要在夜间使用，可在首次启动询问。
2. **编辑器正文宽度**：建议 820 px 左右；用户可切换宽屏，但 V1 不做复杂布局设置。
3. **Dashboard 信息优先级**：建议今日日志和待办优先，热力图次之；若用户更偏回顾可调整。
4. **AI 入口位置**：建议放在显式菜单和报告区，不悬浮在编辑器主操作中。
