# DailyFlow 用户操作手册

本手册面向 DailyFlow V1 的日常使用者，覆盖每日记录、知识沉淀、待办、搜索、分析、历史数据导入、备份恢复和桌面端设置。产品当前以本地数据为主，不要求注册账号，也不依赖 AI 才能使用。

## 1. 首次启动与数据位置

### 1.1 打开应用

- Windows 和 macOS：启动已安装的 DailyFlow 桌面应用。
- Web：在支持的浏览器中打开 DailyFlow 页面。
- 第一次启动会直接进入“工作台”，不需要登录或填写固定模板。

### 1.2 数据保存在哪里

桌面端使用本机 SQLite 数据库，数据目录由应用管理。打开“设置 > 数据与存储”可以查看当前实际目录，不要只根据操作系统猜路径。

桌面数据目录通常包含：

- `dailyflow.db`：日志、知识、待办、报告、历史版本和搜索索引等结构化数据。
- `attachments/`：日志中的图片和附件。
- `backups/`：应用创建的安全快照和备份相关文件。
- `.dailyflow-migration-backups/`：存储位置迁移前生成的保护性备份。

自定义数据目录设置在 Tauri 应用配置目录的 `data-location.json` 中。应用配置目录和数据目录是两个位置，不要把该配置文件当成业务数据备份。

Web 端使用 IndexedDB，Dexie 数据库名为 `dailyflow-web`。数据属于当前浏览器站点存储，没有可自定义的文件夹。清理站点数据、使用隐私清理工具或更换浏览器配置都可能移除数据。

### 1.3 第一次使用建议

1. 先打开“设置”，确认语言、主题、自动保存间隔和桌面行为。
2. 在“每日日志”写一条测试记录，等待状态显示“已保存”。
3. 到“数据 > 备份与恢复”创建第一份完整备份。
4. 如果有历史 TXT，再到“数据 > 导入 TXT”执行预览和导入。

## 2. 界面和常用入口

主导航包括：

- 工作台：今日记录、近期活动和待办摘要。
- 每日日志：按日期编辑日志。
- 时间线：月历、时间线和年度活动热力图。
- 知识库：手动新建知识，以及从日志沉淀的知识条目。
- 待办：轻量个人任务。
- 搜索：跨日志、知识和待办全文搜索。
- 分析：周、月、年统计和周期报告。
- 数据：TXT 导入、归档导出、完整备份与恢复。
- 设置：外观、编辑器、桌面行为和数据位置。

顶栏可以快速打开全局搜索和帮助中心。页面右下角或日志工具栏中的帮助入口会打开应用内快速说明。

### 2.1 常用快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl/Cmd + S` | 立即保存当前日志 |
| `Ctrl/Cmd + K` | 打开设置 |
| `/` | 打开全局搜索 |
| `?` | 打开快捷键帮助 |

如果焦点在编辑器正文中，`/` 优先用于打开 Slash 块菜单；需要全局搜索时可先移出正文，或使用顶栏搜索入口。

## 3. 每日日志

### 3.1 选择日期和补录

1. 打开“每日日志”。
2. 使用日期控件选择要编辑的日期。
3. 使用“前一天”“后一天”快速切换。
4. 选择过去的日期即可补录，不需要创建单独的“补录文档”。

每天对应一份日志。日期是日志的主要定位方式，不建议把多个日期写在同一个标题中。

### 3.2 标题、正文和 Tags

- “日志标题”是顶部输入框，用于快速识别当天记录。建议填写简短主题，例如“排查部署失败”。
- 标题不是必填模板，也不会改变日期归属。
- “日志正文”是主要记录区域。
- “Tags”是可选标签输入框，使用逗号分隔，例如 `部署, 排障, Rust`。
- Tags 是日志的附加分类信息，不替代正文，也不是必填项。当前不会自动把标签写进正文。

### 3.3 自动保存

停止输入一段时间后，DailyFlow 会自动保存标题、正文、标签和结构化内容。工具栏会显示“有未保存更改”或“已保存”等状态。

需要立即写入时：

1. 点击工具栏的“立即保存”。
2. 或按 `Ctrl/Cmd + S`。

看到“已保存”后再关闭窗口或切换设备。不要依赖编辑器中的临时输入状态作为长期存储。

### 3.4 Markdown 快捷输入

编辑器正文的权威存储格式是 Tiptap JSON，Markdown 是输入、显示和导出方式。可以正常输入：

```markdown
## 标题

- 列表项

> 引用内容

`行内代码`

https://example.com
```

标题快捷输入支持半角空格和全角空格。例如输入 `## 标题` 或 `##　标题` 后继续输入内容，会转换为标题节点。代码块中的同样文本不会被当作 Markdown 快捷语法。

### 3.5 Slash 菜单

在空段落开头输入 `/` 可以打开块菜单。可用命令包括：

- 标题、列表和引用。
- 代码块。
- 表格。
- 图片和附件。
- 行内或块级公式。
- Mermaid 图表。

也可以从工具栏插入或调整这些内容。块左侧的拖拽手柄用于调整顺序。

### 3.6 图片、附件、表格、公式和 Mermaid

- 图片和附件：通过工具栏或 Slash 菜单选择本地文件，也可以尝试拖放或粘贴。文件会通过附件通道保存，正文只保留受控引用。
- 表格：插入后可增删行列、调整表头和对齐。
- 公式：使用 KaTeX 语法，支持行内和块级公式。
- Mermaid：在 Mermaid 代码块中编写图表源码。渲染失败时会显示错误和源码，不会执行任意 HTML。

不要手工修改数据库中的附件路径。跨设备迁移时使用完整备份或导出归档。

### 3.7 文档大纲

正文中创建标题后，右侧“大纲”会显示层级。

- 点击大纲条目可跳到对应位置。
- 在较窄窗口中，大纲可能折叠为抽屉。
- 可以在“设置 > 外观或编辑”中关闭右侧大纲。

### 3.8 历史版本

1. 打开一篇日志。
2. 点击工具栏“历史”。
3. 在“日志历史版本”中选择一个版本。
4. 查看只读预览和版本信息。
5. 点击“恢复此版本”。

恢复会生成新的当前内容，并保留恢复前的检查点。恢复后仍建议检查标题、正文和附件引用是否符合预期。

历史版本保留策略可以在“设置”中配置。修改保留策略不会自动恢复已经清理的旧版本。

### 3.9 单篇 Markdown 导入和导出

日志工具栏提供：

- “导入 Markdown”：选择单个 `.md` 文件，转换为编辑器内容。导入前应确认它会替换或更新当前编辑内容，并先保存已有日志。
- “导出 Markdown”：根据当前 Tiptap JSON 生成 `.md` 文件，用于外部编辑、归档或分享。

Markdown 导入导出只针对当前单篇日志。按月目录整理的历史 TXT 请使用“数据 > 导入 TXT”。

## 4. 待办

### 4.1 新建待办

1. 打开“待办”。
2. 点击“新建待办”。
3. 填写“任务标题”。
4. 使用“截止日期”日期控件选择日期；不要手工输入本地化日期文本。
5. 点击“创建待办”。

截止日期可以留空。创建失败时，先检查任务标题是否为空，再确认日期是否通过日期控件选择。

### 4.2 查看和完成

待办页支持“今天”“即将到期”“全部”和“已完成”等视图。

- 点击完成控件将任务标为完成。
- 在已完成视图可以重新打开任务。
- 打开任务详情可以编辑标题、日期或备注。
- 如果任务由日志创建或关联了日志，可以从详情回到对应日志；也可以解除关联。

## 5. 知识库

知识库不是自动把所有日志复制一份。知识条目需要由用户主动新建或从日志沉淀。

### 5.1 手动新建

1. 打开“知识库”。
2. 点击带 `+` 图标的“新建知识”。
3. 选择知识类型。
4. 填写标题、摘要和 Markdown 正文。
5. 保存后从知识列表打开详情。

保存失败时，对话框会保留已填写内容。检查必填项或存储状态后可以直接重试。

### 5.2 从整篇日志沉淀

1. 打开并保存要沉淀的日志。
2. 点击“沉淀整篇日志”。
3. 选择知识类型并确认。
4. 保存完成后打开知识条目检查内容。

沉淀保存的是当时的快照。之后编辑原日志不会自动修改知识条目，编辑知识条目也不会反向修改原日志。

### 5.3 从当前块沉淀

1. 在编辑器中选择一个结构化块或把光标放入目标块。
2. 点击“沉淀当前块”。
3. 选择类型并保存。

知识详情会显示来源日期或来源块。来源仍存在时，可以通过“回到来源日志”跳转；来源被删除时，界面会明确显示不可用。

## 6. 搜索

### 6.1 全局搜索

- 点击顶栏搜索入口。
- 或按 `/` 打开搜索命令。
- 输入关键词后按 Enter，进入完整搜索结果页。

搜索覆盖日志正文、知识和待办。搜索结果按类型展示，可打开对应详情或编辑页。

### 6.2 搜索不到内容时

1. 确认日志已经显示“已保存”。
2. 尝试更短的关键词。
3. 确认当前处于正确的数据端，桌面 SQLite 和 Web IndexedDB 不共享数据。
4. 恢复备份后如果搜索索引仍在重建，等待重建完成后再搜索。

## 7. 时间线、热力图和分析

### 7.1 时间线

“时间线”提供：

- 月历视图。
- 按日期排列的时间线。
- 年度活动热力图。

年度热力图显示所选自然年的完整网格，包含年份切换、月份、星期标签、颜色图例和任务到期角标。格子颜色只表示当天日志数量，任务到期用角标表示。

使用键盘时，方向键按天或周移动焦点，`PageUp`/`PageDown` 按月移动，`Home`/`End` 移到当前行首尾。按 Enter 打开当天日志。

### 7.2 分析

“分析”支持周、月、年切换，并可查看上一周期、下一周期。

周期报告：

1. 选择周期类型和具体周期。
2. 点击“打开周期报告”。
3. 编辑报告标题和正文。
4. 点击“保存报告”。

切换周、月、年或前后周期时，未保存草稿会按周期保留。返回原周期后会恢复草稿。草稿最终仍应点击保存，以免长期只存在临时状态。

## 8. 导入历史 TXT

### 8.1 支持的目录结构

推荐结构：

```text
历史日志根目录/
  202504/
    20250403.txt
    20250404.txt
  202505/
    20250506.txt
```

文件夹名称应以 `YYYYMM` 表示月份，文件名应以 `YYYYMMDD.txt` 表示日期。应用会扫描根目录及其月份子目录，并自动识别日期。

支持 UTF-8、UTF-8 BOM 和 GBK/GB18030 内容。原始文本内容和导入记录会被保留，以便追溯。

### 8.2 导入步骤

1. 打开“数据 > 导入 TXT”。
2. 点击“选择 TXT 目录”，选择月份文件夹的上级根目录。
3. 点击“扫描并生成预览”。
4. 在“TXT 导入预览”中检查路径、识别编码、日期和异常状态。
5. 取消不希望导入的文件选择。
6. 点击“进入导入策略”。
7. 如果已有同日期日志，选择：
   - “保留现有日志并跳过”：保留当前版本，不导入冲突文件。
   - “同日期内容建立新版本”：把导入内容写为同日期日志的新版本。
8. 点击“确认导入 N 个文件”。
9. 在“导入完成”中检查创建、跳过、异常和冲突统计。

扫描和预览阶段不会写入正式日志。确认提交后，一个批次作为一个事务处理；失败会回滚该批次，不会留下半批正式数据。

### 8.3 增量导入和重复文件

可以再次选择同一个根目录执行增量导入。DailyFlow 会根据日期、内容哈希和来源文件信息检测已导入或重复内容。预览中的“同日期已有日志”不一定是重复文件，应按内容决定跳过还是建立版本。

### 8.4 异常文件

常见异常：

- 文件名无法解析日期。
- 月份目录与文件名不一致。
- 文件不是 TXT。
- 编码无法识别或内容无法读取。
- 空文件或只有不可用内容。

异常文件会显示在预览中，不会因为存在异常文件就悄悄跳过。排除不可用文件后再确认导入，并保留原始文件以便修复。

## 9. 导出、备份与恢复

### 9.1 便携导出

打开“数据 > 导出归档”：

1. 选择导出范围，例如全部数据、导入记录等。
2. 选择是否包含软删除内容、附件和导入原始字节。
3. 检查导出估算。
4. 点击“生成并保存导出”。
5. 选择保存位置。

导出的 ZIP 使用权威 Tiptap JSON 生成 Markdown 和 NDJSON，清单包含内容哈希。导出的归档适合迁移和分析，但正式恢复应优先使用“完整备份”。

### 9.2 创建完整备份

1. 打开“数据 > 备份与恢复”。
2. 点击“创建完整备份”。
3. 选择保存位置。
4. 等待校验通过并记录备份文件位置。

完整备份包括业务表、历史版本、附件和可用的 TXT 原始字节。建议在导入、恢复、迁移数据目录或升级前创建备份。

### 9.3 从备份恢复

1. 打开“数据 > 备份与恢复”。
2. 点击“选择备份文件”。
3. 等待文件路径、哈希和内容校验。
4. 检查备份摘要。
5. 勾选“我已确认将用此备份替换当前本地数据”。
6. 点击“确认恢复并替换当前数据”。

当前数据非空时，恢复前会创建安全快照。恢复失败会丢弃 staging，保留当前数据库。恢复完成后应重新打开应用，并等待搜索索引重建。

不要同时打开两个 DailyFlow 进程对同一数据目录执行恢复或迁移。

## 10. 更改桌面存储位置

只有桌面端提供自定义数据目录。Web 端的数据位置由浏览器管理。

1. 打开“设置 > 数据与存储”。
2. 检查当前数据目录。
3. 点击“更改存储位置”。
4. 选择空目录或 DailyFlow 专用目录。
5. 等待应用创建备份、复制数据、校验记录和写入新位置。
6. 按提示重启 DailyFlow。

迁移失败时继续使用原目录，不完整的临时副本会清理。迁移成功提示中会给出原数据备份位置，确认新目录工作正常前不要删除备份。

## 11. 桌面行为与系统设置

Windows 和 macOS 桌面端支持：

- 关闭到托盘。
- 托盘菜单“打开”“设置”“退出”。
- 开机自启。
- 静默启动。

### 11.1 托盘

开启“关闭到托盘”后，点击窗口关闭按钮只会隐藏窗口，进程仍在后台运行。

- 双击托盘图标或选择“打开”恢复主窗口。
- 选择“设置”直接打开设置页。
- 只有选择“退出”才会结束应用进程。

如果托盘图标不可见，检查系统托盘折叠区域和操作系统通知设置。

### 11.2 开机自启和静默启动

- 开机自启：登录系统后自动启动 DailyFlow。
- 静默启动：由系统启动时不立即显示主窗口，通常配合关闭到托盘使用。

Web 端不提供系统自启、托盘和后台常驻能力，设置页会禁用这些选项。

### 11.3 设置项

- 常规：语言、周起始日、关闭到托盘、开机自启、静默启动。
- 外观：跟随系统、浅色、深色、强调色、界面密度、编辑器字号、聚焦或宽屏。
- 编辑：自动保存间隔、右侧大纲等。
- 数据与存储：当前目录、迁移位置和版本保留策略。
- 关于：版本、平台、构建信息、开源许可和用户手册入口。

## 12. Windows、macOS 与 Web 差异

| 能力 | Windows | macOS | Web |
| --- | --- | --- | --- |
| 主要存储 | Tauri + SQLite | Tauri + SQLite | IndexedDB + Dexie |
| 自定义数据目录 | 支持 | 支持 | 不支持 |
| 系统托盘 | 支持 | 支持 | 不支持 |
| 开机自启 | 支持 | 支持 | 不支持 |
| 单篇 Markdown | 导入、导出 | 导入、导出 | 支持浏览器文件流程 |
| TXT 批量导入 | 支持目录选择 | 支持目录选择 | 浏览器提供的目录选择 |
| 完整备份恢复 | 支持 | 支持 | 支持 Web 可用的文件流程 |
| 数据共享 | 不与 Web 自动共享 | 不与 Web 自动共享 | 不与桌面自动共享 |

快捷键使用 `Cmd` 替代 `Ctrl` 时，按 macOS 习惯操作。路径由应用通过文件对话框处理，用户不需要在业务输入框中手工填写 Windows 或 macOS 路径。

## 13. 常见错误与恢复

### 13.1 显示“本地存储暂时不可用”

1. 确认磁盘空间充足。
2. 检查数据目录和备份目标目录是否有写权限。
3. 关闭重复运行的应用实例。
4. 重启 DailyFlow 后重试。
5. 仍然失败时，不要清理数据目录；先复制整个数据目录并保留日志，再检查“设置 > 数据与存储”的当前路径。

如果是用户主动取消文件选择，界面会显示“已取消”，不应当按数据损坏处理。

### 13.2 待办创建失败

- 检查“任务标题”是否填写。
- 日期必须从“截止日期”日期控件选择。
- 重试时保留已填写的标题和日期。
- 如果提示与冲突或存储有关，按提示刷新或检查存储状态。

### 13.3 导入到策略页无法继续

- 返回预览确认至少选择了一个可用文件。
- 检查是否有无法读取的异常文件。
- 确认同日期冲突策略已选择。
- 重新扫描目录，避免在预览期间修改或移动源文件。

### 13.4 导入失败

- 失败批次会回滚，正式数据不会部分写入。
- 保留原始 TXT 文件。
- 检查预览中的编码和日期异常。
- 缩小到单个月份目录重试，定位问题文件。

### 13.5 历史版本恢复失败

- 日志可能已在其他窗口更新，重新打开历史面板。
- 确认历史版本仍存在，且保留策略没有清理该版本。
- 先创建当前日志的备份或立即保存当前内容，再重试。

### 13.6 Web 数据消失

检查是否清理了浏览器站点数据、切换了浏览器配置、使用了新的域名或端口，或处于不同浏览器。Web 本地数据不会自动从桌面 SQLite 读取；只能通过此前导出的备份恢复。

### 13.7 关闭窗口后找不到应用

这是开启“关闭到托盘”后的正常行为。检查系统托盘或菜单栏，选择“打开 DailyFlow”。需要完全结束时，从托盘选择“退出”。

## 14. 数据安全建议

- 每天完成重要记录后确认“已保存”。
- 每周至少创建一次完整备份。
- 批量导入、恢复和迁移前先备份。
- 备份文件保存在不同于应用数据目录的位置。
- 不要把正在运行的 `dailyflow.db` 直接复制为唯一备份。
- Web 端定期导出或创建备份，不要只依赖浏览器存储。
- 升级前保留上一版本备份和一两个可回退的安装包。
