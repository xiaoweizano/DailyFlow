# Knowledge Base

The knowledge base preserves reusable work memory: notes, issues, solutions, decisions, and references.

## Three Sources

- Create an independent item manually.
- Promote a whole journal from **Daily Journal**.
- Select a structured block and promote only that block.

Promotion copies the source into an independent snapshot. Later journal edits do not overwrite the knowledge body.

## Provenance

The knowledge detail page shows the source date and block. Use **Original journal** to return to the source. If it was deleted or is unavailable, the page reports that the source is unavailable while keeping the knowledge readable.

## Recommended Workflow

1. Record the symptom, investigation, and resolution in the journal.
2. Turn the reusable conclusion into a structured block.
3. Promote the selected block.
4. Choose a knowledge type and a clear title.
5. Reuse the item through search or knowledge filters.
