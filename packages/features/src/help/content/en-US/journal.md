# Daily Journal

Each date has one journal. Open **Daily Journal** to write today's work or backfill an earlier date.

## Writing

- Type plain paragraphs.
- Type `# ` or `## ` for headings and `- ` for lists.
- Type `> ` for quotes and three backticks for a code block.
- Type `/` to insert headings, lists, tables, equations, Mermaid diagrams, images, or structured blocks.
- Select text and use the toolbar for bold, italic, links, and heading levels.

Markdown is the fast input format. The document is stored as Tiptap JSON, so there is only one authoritative body.

## Autosave and History

Changes save automatically after editing stops. Title, body, tags, and structured blocks are saved together. Open **History** to inspect or restore a version; the current version is preserved before a restore.

## Structured Blocks

Use structured blocks for issues, solutions, decisions, or reusable checklists. Promote only the selected block, or promote the whole journal. A promoted knowledge item is an independent snapshot and does not change when the source journal changes.

## Single-Document Import and Export

Toolbar import and export actions work on one journal. For legacy monthly TXT folders, use **Data Management > Import**.
