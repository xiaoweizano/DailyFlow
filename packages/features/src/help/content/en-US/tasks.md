# Tasks

Tasks capture short-term actions and do not replace detailed journal entries.

## Create a Task

1. Open **Tasks**.
2. Enter a title.
3. Choose a due date with the date picker.
4. Select **Create Task**.

Use the date picker instead of typing free-form dates. Completed tasks can be reopened when follow-up work is needed.

## Due Indicators

The timeline and annual heatmap mark dates with due tasks. The dashboard surfaces tasks that need attention today.

## Relationship to Journals

Tasks store actions and state. Investigation notes, findings, and solutions belong in the daily journal. Promote mature reusable findings into the knowledge base.
