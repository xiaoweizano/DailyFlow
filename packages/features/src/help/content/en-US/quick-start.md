# Quick Start

DailyFlow is a local-first personal work memory system. Journals, tasks, history, knowledge, and reviews live in one workspace.

## Recommended Flow

1. Open **Daily Journal** and choose a date.
2. Type `/` for block commands or use Markdown shortcuts.
3. Create tasks with the date picker.
4. Use **Search** and **Timeline** to revisit past work.
5. Use **Data Management** to import legacy TXT files, export, or create a backup.

## Main Areas

- **Dashboard** summarizes today's journal, recent activity, and tasks.
- **Knowledge Base** stores reusable issues, solutions, and decisions.
- **Analytics** creates weekly, monthly, and yearly reviews.
- **Settings** controls theme, language, editor, storage, and desktop behavior.

## Data Safety

Desktop data is stored locally in SQLite. The web app uses IndexedDB in the browser. Create a backup from **Data Management** before important changes.

Continue with the Daily Journal, Tasks, Knowledge Base, and Data Management sections for exact workflows.
