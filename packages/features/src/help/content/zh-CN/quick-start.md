# 快速开始

DailyFlow 是本地优先的个人工作记忆系统。它把每日日志、待办、历史检索、知识沉淀和周期回顾放在同一个工作台中。

## 建议的使用顺序

1. 在“每日日志”选择日期，直接记录工作过程。
2. 输入 `/` 打开块菜单，也可以使用 Markdown 快捷输入。
3. 在“待办”中用日期选择器安排截止日期。
4. 在“搜索”和“时间线”中回顾历史记录。
5. 在“数据”中导入旧 TXT、导出或创建备份。

## 常用入口

- “工作台”汇总今日记录、近期活动和待办。
- “知识库”保存可复用的经验、问题和解决方案。
- “分析”生成周、月和年度回顾。
- “设置”管理主题、语言、编辑器、存储位置和桌面行为。

## 数据安全

桌面端数据保存在本机 SQLite 数据库中，Web 端使用浏览器 IndexedDB。重要变更前建议从“数据管理”创建备份。

详细步骤请继续阅读“每日日志”“任务”“知识库”和“数据管理”章节。
