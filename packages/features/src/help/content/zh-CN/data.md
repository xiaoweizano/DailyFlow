# 数据管理

数据管理覆盖历史导入、单篇日志导入导出、完整备份、恢复、索引维护和存储位置。

## 历史 TXT 批量导入

1. 准备按月份命名的目录，例如 `202604`、`202605`。
2. 选择根目录并开始扫描。
3. 在预览中检查识别日期、重复文件、异常文件和编码。
4. 确认策略后提交导入。

支持 UTF-8、UTF-8 BOM 和 GBK。导入事务失败时会回滚本批数据库变更；原始文本会保留。重复执行使用增量导入，不会静默覆盖已有日志。

## 导出与备份

- 导出用于生成可交换的 Markdown 或数据文件。
- 备份包含数据库和附件，是恢复时的首选。
- 恢复前先创建当前数据备份。

## 搜索与分析

全局搜索覆盖日志、知识和任务。索引异常时可在数据管理中重建索引。分析页提供周、月、年报告；切换周期时未保存的草稿会保留。

## 桌面能力

桌面端支持自定义数据目录迁移。迁移会创建迁移前备份，完成后需要重启。关闭到托盘、开机自启和静默启动只影响桌面端；Web 端使用浏览器管理的存储。

## 快捷键

使用 `/` 打开全局搜索，`Ctrl/Cmd + K` 也可以搜索。`Ctrl/Cmd + S` 立即保存日志，`Ctrl/Cmd + ,` 打开设置。具体组合可在设置 > 关于 > 快捷键中查看。
