# 每日日志

每个日期对应一篇日志。打开“每日日志”后，可以补录历史日期，也可以切换到前一天或后一天。

## 编辑方式

- 直接输入普通段落。
- 输入 `# `、`## ` 创建标题，输入 `- ` 创建列表。
- 输入 `> ` 创建引用，输入三个反引号创建代码块。
- 输入 `/` 打开 Slash 菜单，插入标题、列表、表格、公式、Mermaid、图片或结构化块。
- 选中文字后使用工具栏设置粗体、斜体、链接和标题层级。

Markdown 是快速输入方式，文档最终以 Tiptap JSON 保存。不要同时维护两份正文，DailyFlow 会统一转换和保存。

## 自动保存与版本

编辑停止后会自动保存。标题、正文、标签和结构化块都在同一份日志快照中。点击“历史”查看版本并恢复；恢复前系统会保留当前版本。

## 结构化块

结构化块适合记录问题、方案、决策或可复用的检查项。选中块后可以仅沉淀当前块；不选块时可以沉淀整篇日志。知识条目保存的是独立快照，后续修改原日志不会改写已沉淀正文。

## 导入与导出

工具栏的导入和导出用于单篇日志。批量历史数据请使用“数据管理 > 导入”。
