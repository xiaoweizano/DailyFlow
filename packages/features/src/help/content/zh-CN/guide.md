## 快速开始 {#quick-start}

DailyFlow 是本地优先的个人工作记忆工具。每日日志记录过程，待办承接行动，知识库保存以后还能复用的结论。

### 从工作台开始

打开应用后先看工作台。这里汇总今日日志、今日待办、最近知识和最近 12 周活动。

1. 点击“打开今日日志”。如果当天还没有内容，会先出现模板选择。
2. 选择“空白日志”或一个模板。选择后自动进入正文，不需要再点一次确认。
3. 在正文块左侧点击 `+`，或者直接输入 Markdown，例如 `## 你好`。
4. 打开“待办”，填写标题并选择截止日期。日期必须来自日期选择器。
5. 在“数据”中创建一次完整备份，确认本机数据可以恢复。

**预期结果：** 工作台出现今天的日志和待办，左侧导航可以在日志、待办、时间线、知识库之间切换。

**故障恢复：** 如果工作台没有刷新，先返回上一页再进入；如果日志无法保存，保留窗口并检查数据目录和磁盘空间。

### 本地数据边界

桌面端数据默认保存在当前设备的本地数据库和附件目录。DailyFlow 不包含云同步，重装、换机或清理数据前必须创建完整备份。

## 创建并编辑每日日志 {#journal}

每个日期对应一篇日志。日志编辑器围绕“选模板、写正文、看大纲、保存与沉淀”组成一条连续流程。

### 选择模板

新日志标题和正文都为空时，正文区首先显示模板选择页。

1. 查看“最近使用”。这里按最近一次使用排序，最多显示四个。
2. 选择“空白日志”可以不带结构开始记录。
3. 选择日报、周报、问题排查或复盘等内置模板。
4. 选择自定义模板，或者新建一个带名称、说明和初始 Markdown 的模板。

**预期结果：** 选择卡片后立即进入正文，最近使用顺序同步更新。

**故障恢复：** 没有看到模板页时，确认这篇日志是否已经有标题或正文。已有内容的日志不会被强制覆盖。

### 在正文中插入内容

把手移到正文块左侧，或让键盘光标进入一个正文块，会出现一个 `+`。

1. 点击 `+` 打开当前块的插入菜单。
2. 选择标题、列表、任务列表、引用、代码、表格、图片、附件、公式或 Mermaid。
3. 插入内容位于当前块之后，不会把光标之前的文字替换掉。
4. 也可以输入 `/` 打开插入菜单，或直接输入 Markdown 快捷语法。

**预期结果：** 插入菜单只显示一个当前入口，正文保持可编辑，工具栏不会被菜单遮挡。

**故障恢复：** `+` 没有出现时，先把光标放进正文；菜单打开后按 `Esc` 关闭，再重新定位当前块。

### 使用 Markdown 和大纲

在空段落中输入 `## 你好` 或 `##　你好`，按空格后生成二级标题。标题会立即进入右侧大纲。

1. 使用 `#` 到 `######` 创建不同层级标题。
2. 输入 `- ` 创建列表，输入 `> ` 创建引用，输入三个反引号创建代码块。
3. 点击大纲中的标题，可以跳到对应正文位置。
4. 窄窗口下用顶部的大纲按钮打开目录，不挤压正文宽度。

**预期结果：** 标题样式和大纲同时更新，Markdown 语法不会留在正文中。

**故障恢复：** 快捷输入没有转换时，确认光标位于空段落，并删除行首多余空格后重新输入。

### 自动保存和历史

停止输入后，标题、正文、标签和结构化内容一起保存。顶部保存状态会显示正在保存、已保存或失败。

1. 按 `Ctrl/Cmd + S` 可以立即保存。
2. 点击“历史”查看之前的版本。
3. 恢复旧版本会生成新的 revision，不会删除旧历史。

**预期结果：** 保存状态稳定显示，重新打开同一日期后内容仍然存在。

**故障恢复：** 保存失败时不要直接关闭窗口。先保留当前页面，创建备份或复制正文，再检查数据目录权限和剩余空间。

### 从整篇日志沉淀知识

日志保存后，可以在不选择正文块的情况下沉淀整篇日志；也可以选中一个结构化块，只沉淀当前块。

**预期结果：** 知识条目的标题、摘要、纯文本和 Markdown 与日志内容一致，并保留来源日期。

**故障恢复：** 沉淀按钮报错时，先确认日志已经保存且有标题。窗口应保留已填内容，不必重新输入。

## 使用时间线 {#timeline}

时间线用于回看某一天、某个月或某一年的记录。不需要逐月点击“上个月”。

### 快速选择年月

1. 点击时间线顶部的年份按钮。
2. 在年份输入框中输入 `1` 到 `9999` 之间的年份。
3. 使用“今年”“去年”“前年”快速跳转。
4. 点击十二个月网格中的月份，直接打开对应月份。

**预期结果：** 月历、时间线和年度热力图使用同一个年月选择器，选择后立即刷新。

**故障恢复：** 年份无法确认时，检查输入是否为纯数字且位于 `1..9999`。按 `Esc` 可以关闭面板并保留当前月份。

### 阅读绿色活动

月历和年度热力图使用独立绿色色阶表示记录数量。绿色不跟随主题强调色变化。

1. 颜色越深表示当天记录越多。
2. 今天和当前选中日期使用边框区分，不改变活动等级颜色。
3. 任务到期使用角标提示，不等于任务创建日期。

**预期结果：** 切换浅色或深色主题后，活动色仍然可辨认。

**故障恢复：** 某天没有颜色时，检查该日期是否已有已保存日志，再返回时间线刷新。

## 待办：创建、完成与重新打开 {#tasks}

待办只保存需要执行的行动。排查过程、判断和复盘仍然写在每日日志。

### 创建待办

1. 打开“待办”，点击“新建待办”。
2. 输入任务标题，可选填备注。
3. 选择优先级。
4. 使用日期选择器设置截止日期。
5. 点击“创建待办”。

**预期结果：** 新任务出现在当前视图，标题、日期和优先级与输入一致。

**故障恢复：** 创建失败时对话框保持打开。标题错误会显示在标题输入附近，日期错误会显示在日期输入附近；修正后再提交。

### 完成与重新打开

每条待办行尾始终显示文字操作。

1. 未完成任务显示“完成”。点击后任务移入已完成状态。
2. 已完成任务显示“重新打开”。点击后任务恢复未完成状态。
3. 需要修改标题、备注、日期或优先级时，点击“编辑”。

**预期结果：** 完成和重新打开后列表立即更新，失败时恢复旧状态并显示行内错误。

**故障恢复：** 操作没有生效时，刷新当前视图并再次打开任务。持续失败时记录错误提示，再检查本地数据库是否可写。

## 知识库：新建与来源 {#knowledge}

知识库保存可跨日期复用的笔记、问题、方案、决策和参考资料。

### 新建知识

1. 打开“知识库”，点击“新建知识”。
2. 在放大的编辑窗口中填写标题、摘要和 Markdown 正文。
3. 在右侧选择知识类型并检查文档信息。
4. 保存期间按钮会禁用并显示进度。

**预期结果：** 保存成功后进入新知识详情。弹窗本身不滚动，只有正文编辑区滚动。

**故障恢复：** 校验失败会保留全部输入并显示具体字段。存储失败时先创建完整备份，再检查数据目录权限和磁盘空间。

### 从日志沉淀

1. 打开一篇已保存日志。
2. 不选择正文块时，选择“沉淀整篇日志”。
3. 选中一个结构化块时，选择“沉淀当前块”。
4. 检查标题、摘要、类型和正文后保存。

**预期结果：** 知识内容是独立快照，后续修改原日志不会自动改写知识。知识详情可以返回原始日志。

**故障恢复：** 来源日志已删除时，知识正文仍可阅读，页面会标记“来源不可用”。

## 搜索与分析 {#search-analytics}

搜索覆盖日志、知识、待办和结构化块。分析用于查看周、月和年度记录节奏。

### 搜索记录

1. 点击顶部搜索框，或按 `Ctrl/Cmd + K`。
2. 输入标题、正文关键词、标签或任务名称。
3. 在日志、知识、待办和块结果之间切换。
4. 打开结果后继续编辑或回到来源。

**预期结果：** 搜索结果显示上下文，空查询不会触发大范围扫描。

**故障恢复：** 搜不到已知内容时，先检查关键词和当前视图；索引过期的提示出现后，在数据页重建索引。

### 查看分析

1. 在分析页选择周、月或年。
2. 查看记录天数、字符数、完成任务和知识沉淀。
3. 检查趋势、活跃标签和周期报告。
4. 修改报告后等待自动保存，或使用页面提供的保存操作。

**预期结果：** 切换周期不会丢失尚未保存的报告草稿。

## 数据、备份与恢复 {#data}

数据页管理历史 TXT 导入、Markdown 交换、完整备份、恢复和索引维护。

### 创建完整备份

1. 打开“数据”，选择创建完整备份。
2. 选择一个安全位置，不要把备份只放在应用数据目录内。
3. 等待任务完成并确认备份文件和校验结果。
4. 在恢复前再创建一次当前数据备份。

**预期结果：** 备份包含数据库、历史版本和附件，可以离线恢复。

**故障恢复：** 备份失败时记录目标路径和错误原因，检查空间与权限。不要删除现有数据目录。

### 导入和恢复

1. 历史 TXT 按 `202604`、`202605` 这样的月份目录组织。
2. 扫描后先检查识别日期、重复项、异常文件和文本编码。
3. Markdown 单篇导入用于交换一篇日志。
4. 完整恢复失败时，现有数据不会被替换。

**预期结果：** 导入事务完整成功或回滚，恢复后日志、待办和附件均可打开。

**故障恢复：** 恢复后搜索没有结果时，在数据页重建全文索引；重建不会修改日志正文。

## 设置：语言、外观和关闭行为 {#settings}

设置只保存在当前设备。修改后先观察即时预览，再保存需要持久化的值。

### 切换语言

1. 打开“设置 > 常规”。
2. 选择“简体中文”或“English”。
3. 观察导航、工作台、日志、待办、时间线、知识库、搜索、分析和帮助中心。
4. 确认日期、月份、空状态和错误提示也已切换。

**预期结果：** 当前窗口立即使用新语言，不需要重启应用。

**故障恢复：** 仍有旧语言时，记录页面和控件名称。重新进入设置确认语言值已保存。

### 调整外观

1. 打开“设置 > 外观”。
2. 在浅色、深色和跟随系统三张主题卡之间选择。
3. 点击强调色色块，选中项同时显示勾选和边框。
4. 选择紧凑、舒适或宽松密度。

**预期结果：** 选项直接平铺和自然换行，不出现带上下箭头的原生选择器或内部滚动条。

**故障恢复：** 控件显示已选中但页面没有变化时，返回设置确认是否保存失败，必要时恢复“跟随系统”。

### 设置关闭窗口行为

1. 打开“设置 > 常规 > 关闭窗口时”。
2. 选择“每次询问”“始终最小化”或“直接退出”。
3. 默认选择“每次询问”，询问弹窗主操作是“最小化”。
4. 需要记住当前选择时，在弹窗中勾选“记住我的选择”。

**预期结果：** 下次点击窗口关闭按钮时按所选行为执行；退出前会等待未保存日志完成保存。

## 故障排查 {#troubleshooting}

先保留现场，再根据错误出现的字段和位置缩小范围。

### 日志无法保存

1. 查看顶部保存状态和错误提示。
2. 确认数据目录可写、磁盘空间充足。
3. 检查是否在另一个窗口更新了同一日期。
4. 发生冲突时先复制当前正文，再重新加载或恢复较新的版本。

### 待办创建失败

确认标题不为空，截止日期来自日期选择器。字段错误会回到对应输入，对话框会保留其他内容。

### 保存到知识库失败

确认日志已经保存且有标题。根据弹窗显示的具体原因检查字段、数据目录和磁盘空间；不要只依赖通用“请重试”。

### 搜索没有结果

检查关键词和结果类型。恢复数据或索引过期后，在数据页重建索引。

### 时间线数据看起来不对

确认年份输入和当前月份。任务角标代表截止日期，今天的边框只表示日期，不改变绿色活动等级。
