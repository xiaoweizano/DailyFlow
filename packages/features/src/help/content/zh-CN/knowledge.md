# 知识库

知识库保存可以跨日期复用的工作记忆，包括笔记、问题、方案、决策和参考资料。

## 三种来源

- 手动新建：直接创建独立知识条目。
- 整篇沉淀：在每日日志中点击“沉淀整篇日志”。
- 块沉淀：选中结构化块后点击“沉淀当前块”。

沉淀会复制来源内容形成独立快照。知识正文可以在后续继续维护，不受来源日志变化影响。

## 来源追踪

知识详情页会显示原始日志日期和来源块。点击“原始日志”返回来源；如果来源已删除或无法访问，页面会显示“来源不可用”，但知识正文仍然可以打开。

## 推荐流程

1. 在日志中记录问题现象、排查过程和最终方案。
2. 把可复用的结论整理为结构化块。
3. 选中块并沉淀到知识库。
4. 选择知识类型并填写清晰标题。
5. 之后通过搜索或知识库筛选复用。
